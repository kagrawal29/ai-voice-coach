# App Flow Document

## Introduction

This application is built as a modern web app using Next.js 14, TypeScript, and Tailwind CSS. The main purpose is to allow users to initiate audio calls with an AI agent powered by Retell AI. The app uses Supabase for secure user authentication and acts as the database for call records, transcripts, and metadata. The application supports two distinct user roles:

- **Basic Users**: Regular users who can log in, make calls, view their own call transcripts, and access their personal call history along with detailed reports generated by the external Airops API.

- **Admin Users**: Administrators who have read access to all user data, including transcripts and reports across all calls, with the ability to filter data by specific users.

## Onboarding and Sign-In/Sign-Up

When a new user first accesses the application, they are met with a clean landing page that invites them to sign in or create a new account. The sign-up process is straightforward, where users can register using their email credentials. Options for social login may also be available, as provided by the Supabase authentication system, ensuring secure and efficient account creation. For returning users, signing in is similarly simple, requiring the proper credentials before gaining access. If users forget their password, they can initiate a password recovery flow that guides them through resetting it securely. The entire authentication process ensures only authorized users can access the app features.

## Main Dashboard or Home Page

After a successful login, users land on the Main Dashboard which serves as the central hub for all activities. The dashboard features a modern layout with a prominent header, a sidebar, and clear navigation menus. The dashboard displays all the previous calls that the user has made, along with a prominent option to start a new call. The user interface is designed to be responsive and intuitive, enabling users to easily navigate from the dashboard to initiating calls, accessing call history, or exploring other parts of the system. Administrators also have access to an extended version of the dashboard where they can monitor call logs and view reports for all users.

## Detailed Feature Flows and Page Transitions

Once on the dashboard, the user can navigate to a call page where he can initiate an audio call by clicking the 'Start a web call' button. Clicking 'Start Call' button transitions the interface to a dedicated call view where the audio session begins. When the user decides to end the call by clicking the 'End Call' button, the session is terminated and the complete transcript is immediately displayed on the same page, without requiring navigation elsewhere. The call data, including metadata such as duration, is automatically saved in Supabase. Users can access the History section of the app to view all their past calls, with options to search, filter, and paginate through the records. By selecting any call record, they can navigate to a detailed call page that displays both the full transcript and a comprehensive call report generated by the Airops API. This report summarizes key insights and outcomes from the call. For administrators, there is a special panel that aggregates call details across all users, providing full oversight of call histories, transcripts, and detailed reports.



## Error States and Alternate Paths

The application is designed to handle errors and alternate paths with clarity and simplicity. If a user inputs incorrect credentials during login, a clear error message is shown, inviting them to try again or use the password recovery option. During an active call, if there is a network issue or the API for real-time transcription does not respond in time, the user is informed via an on-screen notification and given the option to retry the operation. In cases where data fails to load, either due to connectivity issues or API timeouts, fallback pages or loading indicators ensure that the user is always aware of what is happening. These error states ensure the flow remains robust, guiding users back to the correct steps to continue with their work seamlessly.

## Conclusion and Overall App Journey

The journey of the user begins at a welcoming landing page where account creation and sign-in are straightforward and secure through Supabase. Once logged in, users enter a comprehensive dashboard that displays their previous calls and allows them to start a new call. When starting a call, they are directed to a dedicated call page where they can interact with the Retell AI agent. After completing a call, the transcript is immediately available on the same page.

The History section allows both users and administrators to search, filter, and review past calls, with each call record linking to a detailed page showing both the transcript and a comprehensive analysis report generated by the Airops API. Through robust error handling and well-defined account management processes, the complete user experience flows smoothly from initial sign-up to everyday usage, fulfilling the application's aim to provide an efficient, interactive platform for AI-driven communications.
