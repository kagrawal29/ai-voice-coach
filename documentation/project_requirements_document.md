# Project Requirements Document

## Project Overview

We are building a modern web application using Next.js 14, TypeScript, and Tailwind CSS that lets users make audio calls with an AI agent powered by Retell AI. The main purpose of this application is to provide users with a simple and interactive platform where they can call an AI agent, view live transcriptions in a chat format, and later review detailed reports and transcripts of their conversations. This helps users gain insights from their interactions and allows administrators to have an overall view of the calls happening on the platform.

This application is being built to streamline communication and analysis of AI-driven engagements. The key objectives include seamless user authentication via Supabase, reliable real-time transcription during audio calls, efficient logging and retrieval of past call data, and easy-to-read detailed reports generated by an integrated API. Success will be determined by a smooth user experience, quick call initiation and termination, and robust data management that supports scaling as user interactions grow.

## In-Scope vs. Out-of-Scope

**In-Scope:**

*   Secure user authentication via Supabase.
*   Role management with two distinct user types:
    - **Basic Users**: Regular users who can make calls, view their own call history, access their transcripts and reports.
    - **Admin Users**: Administrators with elevated privileges who can view call records across all users, access all transcripts and reports, and filter data by user.
*   A dashboard for initiating audio calls with an AI agent.
*   Logging all call details including transcripts and metadata (such as duration, etc.) in Supabase.
*   A dedicated History section to view all past call interactions with detailed call reports.
*   Detailed call reports generated via an external API that summarizes call outcomes.
*   Features to search, filter, and paginate through historical call records.

**Out-of-Scope:**

*   Any video or chat-based (non-audio) call functionalities.
*   Customization settings for call preferences (like language selection or transcription display options).
*   Alerts or notifications for call completions or report readiness.
*   Data privacy or storage duration policies beyond standard Supabase capabilities.
*   Additional advanced features such as complex analytics dashboards beyond the basic reports provided by the API.

## User Flow

A user first accesses the application landing page and is prompted to log in using their credentials. The authentication is managed through Supabase, ensuring that only authorized users can enter the system. After a successful login, users are taken to the Dashboard, which serves as a central hub where they can view all their previous calls and have an option to start a new call.

Once on the Dashboard, the user clicks the “Start a web call” button to go to the call page and begin an audio call session with the Retell AI agent. When the call ends (via the “End Call” button), the system logs the complete transcript and associated metadata. Users can then navigate to the Call History Page to search, filter, and paginate through past calls, viewing both full transcripts and detailed reports generated through the external API.

## Core Features

*   **User Authentication and Role Management:**

    *   Secure user login and session management through Supabase.
    *   Role-based access controls enabling administrators to review all user calls.

*   **AI Audio Call Sessions:**

    *   Ability to initiate an audio-based call session with a Retell AI agent.
    *   API interactions managing AI responses in real time.
    *   Immediate access to call transcript after call completion on the same page.

*   **Call Logging and History:**

    *   Automatic storage of complete call details (transcript, metadata, duration) in Supabase.
    *   A dedicated History section for reviewing all past calls with search, filter, and pagination options.
    *   Individual call detail pages to access full transcripts and detailed reports.

*   **Detailed Call Reports:**

    *   Integration with an external API to fetch and display a comprehensive call report summarizing key call outcomes.
    *   Accessible through the call detail page alongside the complete call transcript.

## Tech Stack & Tools

*   **Frontend:**

    *   Next.js 14 (using the app router) with TypeScript for robust, server-rendered pages.
    *   Tailwind CSS for a modern, responsive user interface.

*   **Backend & Storage:**

    *   Supabase for authentication, user data management, and storage of call records.

*   **AI Integration:**

    *   Retell AI integration for managing audio call functionalities and fetching transcripts.
    *   An external API (Airops API) to generate detailed call reports and analytics.

*   **Additional Tools & IDE:**

    *   Windsurf: A modern IDE with integrated AI coding capabilities to streamline the development process.
